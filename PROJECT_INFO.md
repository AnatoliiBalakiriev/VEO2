# Інформація про проект

## 📋 Опис

**Агент пошуку квитків Укрзалізниці** - це автоматизований Python-агент для пошуку та аналізу квитків на поїзди на офіційному сайті Укрзалізниці (booking.uz.gov.ua).

## 🎯 Призначення

Агент призначений для:
- Автоматизованого пошуку квитків за маршрутом та датою
- Моніторингу доступності квитків
- Аналізу цін та розкладів
- Збереження результатів у зручних форматах
- Інтеграції з іншими системами

## 🏗️ Архітектура

### Основні компоненти

1. **UkrzaliznytsiaAgent** - базова версія агента
2. **UkrzaliznytsiaAgentV2** - покращена версія з конфігурацією
3. **Config** - система конфігурації
4. **TicketInfo** - модель даних квитка
5. **Допоміжні модулі** - логування, фільтрація, збереження

### Технології

- **Python 3.8+** - основна мова програмування
- **Selenium** - автоматизація браузера
- **Chrome WebDriver** - управління Chrome
- **BeautifulSoup4** - парсинг HTML (запасний варіант)
- **Requests** - HTTP запити
- **Colorama** - кольоровий вивід
- **Tabulate** - форматування таблиць

## 💻 Приклади використання

### Базовий пошук

```python
from ukrzaliznytsia_agent_v2 import UkrzaliznytsiaAgentV2

with UkrzaliznytsiaAgentV2() as agent:
    agent.open_website()
    tickets = agent.search_tickets("Київ", "Львів", "25.12.2024")
    agent.display_tickets(tickets)
    agent.save_tickets(tickets, format_type="json")
```

### Пошук для кількох маршрутів

```python
routes = [("Київ", "Харків"), ("Київ", "Одеса")]
results = agent.search_multiple_routes(routes, "25.12.2024")
```

### Фільтрація результатів

```python
# Квитки дешевше 1000 грн
affordable = agent.filter_tickets(tickets, max_price=1000)

# Ранкові поїзди (6:00-12:00)
morning = agent.filter_tickets(tickets, departure_time_range=(6, 12))
```

## ⚙️ Конфігурація

### Основні параметри

```python
# Браузер
BROWSER_CONFIG = {
    "headless": False,        # Фоновий режим
    "timeout": 10,            # Таймаут (секунди)
    "window_size": "1920,1080"
}

# Пошук
SEARCH_CONFIG = {
    "delay_between_searches": 2,  # Затримка між пошуками
    "max_retries": 3              # Максимум спроб
}

# Безпека
SECURITY_CONFIG = {
    "rate_limiting": True,        # Обмеження частоти
    "max_requests_per_minute": 30 # Максимум запитів/хв
}
```

### Змінні середовища


## 🔒 Безпека та етика

### Вбудовані захисти

- **Обмеження частоти** - не більше 30 запитів на хвилину
- **Випадкові затримки** - 1-5 секунд між запитами

## 🐛 Діагностика проблем

### Поширені помилки

1. **"ChromeDriver не знайдено"**
   - Встановіть Chrome браузер
   - Оновіть webdriver-manager: `pip install --upgrade webdriver-manager`

2. **"Сайт не завантажується"**
   - Перевірте інтернет-з'єднання
   - Спробуйте без headless режиму
   - Перевірте URL в конфігурації

3. **"Елементи не знайдено"**
   - Оновіть CSS селектори в `config.py`
   - Збільшіть таймаути
   - Перевірте структуру сайту

### Налагодження

```python
# Детальне логування
import logging
logging.basicConfig(level=logging.DEBUG)

# Запуск без headless режиму
agent = UkrzaliznytsiaAgentV2(headless=False)
```
